# 💅 BeautyLady

> Proyecto desarrollado con **React** como parte de mi formación en desarrollo Front-End.

BeautyLady es una tienda web inspirada en un emprendimiento de belleza, creada para poner en práctica los principales conceptos aprendidos durante el curso de **React**.

El proyecto busca ofrecer una experiencia simple, clara y visualmente atractiva para conocer los servicios y productos relacionados con el mundo de la belleza. ✨

* 🏠 Página de inicio con presentación de BeautyLady.

## 🚀 Instalación y ejecución

### 1. Clonar el repositorio

Abrir una terminal y ejecutar:

```bash
git clone https://github.com/devlopezagus/project26242.git
```

### 2. Ingresar a la carpeta del proyecto

```bash
cd project26242
```

### 3. Instalar las dependencias

```bash
npm install
```

### 4. Ejecutar el proyecto

```bash
npm run dev
```

Luego abrir en el navegador la URL indicada por Vite, normalmente:

```text
http://localhost:5173/
```

## 🎨 Diseño

El diseño de BeautyLady está inspirado en una estética femenina, delicada y minimalista.

Se utilizaron variables CSS para mantener una paleta de colores coherente y facilitar futuras modificaciones del diseño.

La tipografía principal utilizada para la identidad de marca es **Kaushan Script**.

El sitio fue desarrollado siguiendo un enfoque **Mobile First**, adaptándose progresivamente a:

📱 **Celular** → 📲 **Tablet** → 💻 **Desktop** → 🖥️ **Pantallas grandes**
